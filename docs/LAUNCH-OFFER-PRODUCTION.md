## Payment handoff

The owner authorized opening payments. Enabling via the admin API succeeded,
but subsequent receiver validation identified example account/holder values.
Payments were disabled again (integration revision 2). No purchase orders existed
after this check. The owner will provide real banking information later.
The paid plan remains visible; accepting new orders is paused. No real bank
transfer, successful SePay delivery or payment-to-entitlement flow was verified.

1. In SePay, connect the real receiving account via **Ngân hàng → Kết nối thêm**.
   Complete bank consent/OTP yourself. See [bank connection instructions](https://docs.sepay.vn/them-tai-khoan-ngan-hang.html).
2. In https://quantik.io.vn/admin/config/integrations, configure that bank,
   account number and holder. Set a shared webhook secret privately in this form
   and in SePay; do not send it through chat. The existing secret is masked.
3. Create a SePay webhook for incoming money on that same account:
   - URL: `https://quantik.io.vn/api/v1/webhooks/sepay`
   - Authentication: **API Key**, using the same shared secret.
     Expected header: `Authorization: Apikey <shared secret>`.
   - Send transactions even when SePay does not recognize a payment code;
     the backend extracts its `QTK` plus 16 hexadecimal-character order reference
     from the transfer content. Keep the full transfer content generated by checkout.
   - Initially omit optional payment-code/VA filters; these must match the actual
     bank configuration if enabled later.
   See [official webhook setup](https://developer.sepay.vn/vi/sepay-webhooks/tao-webhook).
4. Check receiver identity and webhook configuration, enable payments in the
   admin integration, then verify one real order with its exact amount/content.
   Confirm the received bank transaction, successful webhook response and PAID
   order with the correct entitlement. Do not inject a fake successful payment
   into the production database to test this.

No SePay REST API token is needed for the implemented inbound webhook flow.
